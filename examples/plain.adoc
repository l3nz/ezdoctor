This is a sample document to verify that the standalone

== Features

AsciidoctorJ bundles:

* JRuby runtime
* Asciidoctor Ruby gem
* Java API wrappers

[source,java]
----
Asciidoctor asciidoctor = Asciidoctor.Factory.create();
String html = asciidoctor.convert("Hello, *World*!", Options.builder().build());
----
